# Welcome to Web Loom Project

## How can I edit this code?

There are multiple ways to edit and customize your application.

### **Use VS Code**

Simply open your project in vs code and start.

All changes made through vs code are automatically saved and committed to this repository, making development fast and seamless.

---

### **Use Your Preferred IDE**

If you prefer working locally, you can clone the repository and make changes using your own development environment.

Make sure you have **Node.js** and **npm** installed (recommended via nvm).

Follow these steps:

```sh
# Step 1: Clone the repository using the project's Git URL
git clone <YOUR_GIT_URL>

# Step 2: Navigate into the project directory
cd <YOUR_PROJECT_NAME>

# Step 3: Install dependencies
npm install

# Step 4: Start the development server
npm run dev
```

Any changes you push will automatically sync with Web Loom project.

---

### **Edit Files Directly in GitHub**

* Open the repository on GitHub
* Navigate to the file you want to edit
* Click the **Edit (✏️)** icon
* Make your changes and commit

---

### **Use GitHub Codespaces**

* Go to your repository’s main page
* Click the **Code** button
* Select the **Codespaces** tab
* Launch a new Codespace
* Edit, commit, and push changes directly from the cloud
